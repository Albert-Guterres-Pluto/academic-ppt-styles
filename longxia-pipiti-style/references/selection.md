# 选型与逐页排版

四种风格可以覆盖同一份内容。选型看观众需要在哪一步看见什么，以及页面之间怎样承接。主题与受众影响视觉语气、素材和读者预备知识。用户的明确选择优先。

## 整套演示的主风格

先用一句话写出演讲目标，找出全稿反复出现的讲述动作。用一两个内容代表页验证选择。下表给出判断依据，可以结合多项。

| 本次主要讲述方式 | 可以优先试的结构 |
| --- | --- |
| 先概览，再沿时间、范围或指标组织证据 | 旧版的上、下边条和编号标题，正文轮换时间轴、指标和图文 |
| 逐步解释关联，调整关系图中的对象或分类 | 过渡版的固定对象、胶囊和箭头，用同位状态页或平滑串联 |
| 讲解同一章节里的例子、判断和成组信息 | 新版 A 的稳定章节框架、题块、分组和节奏化揭示 |
| 以一张图、坐标关系、构造或公式带动讲解 | 新版 B 的细边框、固定图形和逐步显现的标注 |

多种选择都成立时，看哪套布局能让关键证据更早看懂，并让全稿的重复结构更自然。主题与现成素材提供进一步线索。用户只说“做个学术 PPT”时从提纲推断目标，信息够就继续，无需先让用户选风格。

## 同一主风格内逐页选择

| 单页任务 | 版式动作 |
| --- | --- |
| 先让观众定位主题或阶段 | 用封面、章页或单一引导问题建立位置感 |
| 比较数量、趋势或两个条件 | 用同刻度图表、简表或并排对照，标出关键变化 |
| 展开关系或过程 | 用流程、时间轴、胶囊和短标注。对象移动时保留位置参照 |
| 引出推理、案例或结论 | 用题块、图形或对照框，按理解先后安排出现顺序 |
| 需要数据、简图和结论同场 | 先定画面焦点，重要证据放附近，其余放到下一击或下一页 |

复用标题基线、章节编号、页脚与配色职责。主结构中的更换可服务于章节转折或图表可读性。用户希望同稿明显混用多个风格时，保留共用的页码、对齐基线和命名，交代转换处。

## 同题可以如何变化

以“校园温度观测”为例。同一组数据要突出两次采样和温差，可用旧版的时间轴。要看采样时刻与温差的对应，可用过渡版的胶囊关系。要请听众判断异常来源，可用新版 A 的题块。要讲两个样点点位在坐标图里怎样变化，可用新版 B 的图解。指定新版 A 时，院校报告、活动复盘与成果演示同样可以把它的题头和章节规则移到各自的页面任务中。
