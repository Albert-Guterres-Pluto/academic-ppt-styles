# 配色、编号与图标

## 配色来自本次演示

1. 先确定色彩职责。主强调色可用于边条、章号、标题和当前步骤，浅色用于题块或分区，正文用高对比深色。
2. 优先使用用户指定色。机构或品牌有规范时在允许的色板中选清晰的强调色，并兼顾页面背景。品牌色过浅时可用深色正文，浅品牌色留在填充或边框。无品牌要求时，从主题物象、素材或表达语气取色。说明选色理由，核对投影和小字号。
3. 比较图、过程图需要分类色时，为同一类别保留同色，也用标签或图例提供识别线索。换主色时一起调整浅底、文字和边框对比度。保留版式、索引与动画规则。

参考样本中，《简易逻辑》使用学校的品牌绿，《涉外法务》使用学院的主题紫，《氟的发现》的暖色来自原作者对主题的取色。院校介绍也会从品牌色中选可读的强调色。它们记录了选择过程，可用其他主题和品牌色重做同一版式。

## 编号与图标

- 章节编号保持位置、尺寸、数字基线和同级标题之间的距离。可用原生圆形加数字实现，并让数字居中。步骤多时可用按需增减的文字或短标签。用箭头表达实际的顺序、方向或对应关系。
- Office 或 WPS 内置图标库可用时，选语义明确且线宽一致的图标，按编辑环境支持的方式保留矢量。素材库不可用时，可使用用户授权素材或用可编辑基本形状表达简单的编号、关系和标注。公开示例使用自制或明确获准分享的素材。
- 原作者将 2014 年以后南京地铁导视作为灵感。可研究出入口编号、方向箭头和说明文字在同一系统中的分工，再提炼到 PPT 的章节、分组和步骤。南京南站的公开答复记录了编号、导向指引与图解在不同阅读位置的使用。 [南京南站导向说明](https://www.nanjing.gov.cn/xxgkn/jytabljggk/2023njytabl/shirddbjy/202312/t20231205_4115529.html)
