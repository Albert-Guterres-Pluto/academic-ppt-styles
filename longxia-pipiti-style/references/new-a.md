# 新版学术风格 A

用固定的题头和章节线索把复杂内容拆成可讲述的单位。常见构成包括上下通栏、章号、题块和按需出现的页底索引，也有顶部圆角题头与底部进度表示的原稿。参考 [同一页的两套主题色](visuals/new-a.png)。

## 布局可随页面变化

| 页面任务 | 版式和揭示方法 |
| --- | --- |
| 先给问题，再给证据或答案 | 上方题干配大块浅色例题区。题干留在入场状态，提示和结论各用一次点击 |
| 按小节解释分组或层级 | 章号和题头固定。图标、短标题与解释同组出现。层级关系可用箭头或对照 |
| 讲跨时间的过程 | 固定题头与正文起点。新增一条时，保留之前的条目位置，让当前进度有明确提示 |
| 说明趋势、比较或图形 | 复用原有章节标记与标题基线，把题块空间给图表、证据或简图 |

正文常见约 24–28 pt，章节标题约 28–36 pt。进度标签和页脚用于确实要定位的小节。用浅色突出例题或事件区，正文和重点保持对比。封面、正文、收尾的条框厚度可有差异，整套从用户品牌或主题取色。参见 [取色规则](visual-system.md)。

## 放映

通常可以用约 0.5 秒的页内淡化表示讲述步骤。跨章可用推进，句读停顿可用约 0.7 秒的页间淡化。例题条件或图形位置变化时可用对象级平滑，原稿常见显式时长约 1.5–2.0 秒。逐条累积也可通过同位状态页直接翻页。

## 原稿观察

| 原稿 | 页面结构与本次取色 |
| --- | --- |
| `新版学术风格A-简易逻辑七家湾.pptx` | p7–8 是题块与点击揭示，p35–40 是逐项判断。边条和浅绿题块取自该项目的学校色系。常见约 0.5 秒页内淡化，跨页有淡化、平滑和推进。 |
| `新版学术风格A-AHU-涉外法务.pptx` | p4 是图标组，p10–11 是层级变化。紫色来自该项目的学院主题色。样本按小节成组淡入，跨页可见推进、淡化和平滑。 |
| `新版学术风格A-AHU-氟的发现.pptx` | p4–7、p21–25 固定版面逐条累积，暖色随题目选取。样本靠同位拆页和直接翻页完成节奏。 |

这些观察用于复用页面组织和讲述动作。换主题时，仍可保留同一章号、页框、题块、对象和点击顺序，再跟随项目改变配色。
