# 动画实现与核验

PowerPoint 的**对象动画**、**页面切换**与**分步状态页**可同时存在。一张静态预览通常显示整页对象。用动画窗格、读取 PPTX 时间轴或实际放映来核对逐步揭示。样本的播放参数见对应风格指南。

## 选择实现

| 讲述动作 | PowerPoint 做法 |
| --- | --- |
| 讲者先给观点，再补支持它的图、标签和解释 | 用“淡化”进入。首对象设“单击时”，同一讲述单位其余对象设“与上一动画同时”，通常 0.50 秒。需要自动接续的少数步用“上一动画之后”。 |
| 同一概念、图形或时间线在前后状态中移动或重排 | 复制原页，保留可追踪的对象，在后一页设“平滑”，优先选“对象”。保持页框、页眉和重复元素坐标稳定。若同类对象配对不稳定，在两页的选择窗格给对应对象设置相同、以 `!!` 开头的唯一名称，并放映核对轨迹。 |
| 稳定的讲义页面逐条累计 | 复制页面，保留已讲条目坐标，新增一条并切换强调色。需要快速清晰的翻页节奏时使用“无”切换。 |
| 进入新小节或重置讲述空间 | 按风格选择直接切页、推进或淡化。需要平滑移动的共有对象由进入页的切换承载。 |

## 落到可编辑 PPTX

优先用宿主可用的原生动画编辑器，以便保留已有动画和复杂时间轴。工具只能导出静态 PPTX 时，可在导出完成后运行 [跨平台动画脚本](portable-motion.md)，添加点击淡化、淡化切换、推进或按对象平滑。脚本只依赖 Python 3 标准库，生成新文件。

- 以 PowerPoint 的动画窗格与切换面板设置效果。已有同风格原稿时，可在副本中复用代表性页，修改现有对象并检查动画目标。跨页迁移涉及母版、对象 ID 和媒体时优先用 PowerPoint 自身的复制操作。
- 若已有 Windows PowerPoint 自动化环境，可加对象淡化。下面的参数依次是对象、淡化效果、整对象、触发方式。下一次点击用 `1`，与上一动画同时用 `2`，上一动画之后用 `3`。按实际播放顺序调用，并在保存后复核。

  ```powershell
  $sequence = $slide.TimeLine.MainSequence
  $lead = $sequence.AddEffect($label, 10, 0, 1)
  $lead.Timing.Duration = 0.5
  $paired = $sequence.AddEffect($picture, 10, 0, 2)
  $paired.Timing.Duration = 0.5
  ```
- 先确认导出路径支持所需效果。补动画后避免再次用静态编辑器重存成稿。若环境只能交付静态文件，可用同位状态页表达揭示次序，交付时说明可用的播放方式。

## 复核

1. 检查页数、画幅、版式和字体。静态图主要检查字、图、框的位置和可读性。
2. 有支持相应效果的播放器时，检查首尾、一个含页内揭示的章节和一个含平滑的页面对。核对入场、点击顺序、同时出现的对象、停顿以及翻页设置。有媒体时试播。
3. 在当前工作目录下可用只读脚本提取 XML 中的实际设置。脚本位于本技能的 `scripts/inspect_motion.py`，仅依赖 Python 3 标准库。路径按技能实际位置调整。

   ```console
   python "scripts/inspect_motion.py" "成稿.pptx" --summary
   python "scripts/inspect_motion.py" "成稿.pptx" --pages 5 6 --shapes
   ```

   `transitions` 在分页记录中依次保留主切换和备用分支。例如 `morph` 后跟 `fade` 时，该淡化是兼容分支。切换 `dur`、自动翻页 `advTm` 和对象 `dur_ms` 以毫秒计。对象项中的 `clickEffect`、`withEffect`、`afterEffect` 对应三个触发时机。脚本报告已写入的设置，实际播放结果需通过放映或动画窗格确认。

四种风格的指南合计来自 7 份学术原稿、319 页。公开对照图由自制演示导出。各指南的原稿定位记录实际分析的页号。另两份英语综艺样本用于核对目录中的类型标签。
