# 龙虾屁屁踢

## 选风格和版式

用户指定主风格、原稿、颜色、页数或播放方式时，按要求制作。只给主题和提纲时，先推断受众和要讲清楚的核心问题，再用 [选型与逐页排版](references/selection.md) 选主风格。信息足够就直接制作，交付时简要说明依据。四种风格都可以用于同一个主题。

缺少实测值、正式地图或品牌色值时，可用明确标记的示例、占位或暂定配色推进排版，并说明需要补齐的输入。

| 风格 | 参考样本中的结构和节奏 | 指南 |
| --- | --- | --- |
| 旧版学术风格 | 上下边条、编号标题、机构识别、时间轴与大数字。常在跨页中推进。 | [旧版](references/old.md) |
| 过渡版学术风格 | 圆章号、胶囊、语义色和箭头。保持锚点，逐步展开关系。 | [过渡版](references/transition.md) |
| 新版学术风格 A | 固定题头和章节线索，题块或成组内容随讲述揭示。 | [新版 A](references/new-a.md) |
| 新版学术风格 B | 四边细框、固定图形与标注，推导和结论在页内逐步出现。 | [新版 B](references/new-b.md) |

“过度版”也对应过渡版。读取所选指南后，按每页任务选择图表、图解、图文对照、例题块或状态页，并让页框、标题位置、编号层级和强调方式贯穿全套。颜色随品牌、主题和可读性确定。使用 [配色、编号与图标](references/visual-system.md) 选择或构造元素。

## 制作和验证

1. 按讲述顺序写下每页初始状态、每次点击之后出现的内容和最终画面。按所选风格组织页内揭示、直接翻页、推进或平滑。
2. 用宿主可用的 PPTX 工具排版，保持文字、图形、公式和表格可编辑。参考稿通常为 16:9。需添加、保留或核验动画时，读 [动画实现与核验](references/motion.md)。静态工具导出后可用随附 Python 3 脚本给副本添加常见原生效果。
3. 检查投影可读性、逐击顺序和翻页节奏。有渲染或放映工具时直接查看成稿。只有文件编辑能力时用时间轴检查脚本。只有文本能力时交付逐页版式与放映分镜，并说明验证到哪一步。

各风格指南用同一题目的自制对照页展示差异。原稿定位记录所观察的样本和页码。技能内路径以本文件所在目录为准。[跨 Agent 使用](references/portable-use.md)
